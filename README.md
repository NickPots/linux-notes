# Linux Notes

Personal notes and lab write-ups from learning Linux and systems administration. I write them down to remember what I learned, and to share the commands, mistakes and fixes along the way.

## Environment

The notes are based on hands-on practice with:

- Arch Linux
- Ubuntu
- macOS (where relevant, for cross-platform labs)

Commands may differ slightly between distributions. Where it matters, the note says which one it applies to.

## How the notes are written

- **Practical first:** commands you can copy and try, with a short explanation of what they do
- **Mistakes included:** lab write-ups have a "lessons learned" section covering what went wrong along the way
- **No personal data:** IP addresses, usernames and hostnames are replaced with placeholders
